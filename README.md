# Пространство (PrivateSpace)

Приложение с экраном PIN, где разные PIN открывают разные «пространства»:
основной — ваши заметки и файлы, запасной — пустое пространство с обычными настройками.
Выглядят они одинаково; по экрану блокировки и файлам нельзя понять, сколько пространств существует.

## Как устроено
* Контейнер: соль + 4 слота фиксированного размера. Слот хранит ключ пространства, зашифрованный ключом из PIN
  (PBKDF2-HMAC-SHA256, 120 000 итераций) и ещё раз ключом Android Keystore (привязка к устройству).
  Неиспользуемые слоты — случайные байты.
* Данные пространства — один зашифрованный файл (AES-256-GCM), добивается случайными данными до кратного 64 КБ.
* Файлы шифруются потоково кусками по 64 КБ, у каждого файла свой ключ; обрезка/перестановка кусков обнаруживается.
* Всё лежит во внутреннем хранилище приложения (не видно по USB/MTP и другим приложениям), резервные копии отключены.
* FLAG_SECURE: нет скриншотов, пустая картинка в списке приложений и при трансляции экрана.
* Защита от подбора: паузы после 5-й неверной попытки; опционально стирание после 10 попыток.
* Блокировка при выходе из приложения и при встряхивании.

## Ограничения
Приложение не может подменить экран блокировки Android: оно работает как собственный «сейф» со своим PIN.
Данные на устройстве вне приложения (галерея и т.д.) остаются видны, пока их не перенесёте и не удалите оригинал.
Если удалить приложение или сбросить хранилище ключей, данные восстановить нельзя.

Ядро (`core/`) — чистый Kotlin с юнит-тестами: `gradle testDebugUnitTest`.
